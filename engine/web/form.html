Started with ./run.sh --setup, Save submits the profile to your agent home directly. Opened as a plain file, it downloads profile_form.json; submit that with the command below. Every submission is kept and the newest entry wins.

./run.sh intake form profile_form.json

Start from a CV or cover letter you already have

The original is kept as the wording reference for tailoring, and its text is extracted for the agent to turn into profile entries. Supported: .pdf, .docx, .txt, .md. A file already imported (same content) is never imported twice.

Method 1: from the command line

./run.sh intake cv  path/to/my_cv.pdf
./run.sh intake cl  path/to/a_letter_I_sent.docx

Method 2: copy the files into the intake folders

Copy your CVs into the cv folder and your cover letters into the cl folder below (both are created empty with your agent home), then click Update. Every scheduled run also picks up new files there.

CV folderinputs/intake/cv/
Cover-letter folderinputs/intake/cl/

The Update button works when the form is opened from the Job Agent app. Opened as a plain file, use this instead after copying the files:
./run.sh intake scan

You can combine routes: documents now, form entries later. When a newer entry differs from an older one from the other route, the newest is used and the change is listed for you to confirm:

./run.sh intake conflicts
./run.sh intake resolve 1 keep-previous
