# Job Agent on Windows, from the code

Most people should use the ready-made installer instead: download
**JobAgent-Windows-Setup.exe** from the
[Releases page](https://github.com/manpmanp/job-agent-engine/releases/latest)
(no Python needed).

To run it from the code:

1. Install Python 3.9 or newer from
   [python.org/downloads](https://www.python.org/downloads/). In the
   installer, tick **Add python.exe to PATH**.
2. Double-click **Job Agent.bat** in this folder.
   - If Windows shows "Windows protected your PC", click **More info**,
     then **Run anyway**.
   - The first start prepares itself (about a minute) and asks where to
     keep your job search (press Enter for the `JobAgent` folder in your
     user folder).
3. The app opens in your browser. Keep the black window open while you
   use it; close it, or use **Settings > Quit the app**, to stop.
