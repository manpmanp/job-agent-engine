# Job Agent on Linux, from the code

Most people should use the ready-made package instead: download
**JobAgent-Linux.tar.gz** from the
[Releases page](https://github.com/manpmanp/job-agent-engine/releases/latest)
(no Python needed).

To run it from the code:

1. Install Python 3.9 or newer with venv support, for example
   `sudo apt install python3 python3-venv` (Debian, Ubuntu).
2. Run `./job-agent.sh` in this folder (or double-click it, if your file
   manager runs scripts).
   - The first start prepares itself (about a minute) and asks where to
     keep your job search (press Enter for `~/JobAgent`).
3. The app opens in your browser. Keep the terminal open while you use
   it; press Ctrl+C, or use **Settings > Quit the app**, to stop.
