# Job Agent on a Mac, from the code

Most people should use the ready-made app instead: download
**JobAgent-macOS.dmg** from the
[Releases page](https://github.com/manpmanp/job-agent-engine/releases/latest)
(no Python needed).

To run it from the code:

1. Install Python 3.9 or newer, if you do not have it:
   [python.org/downloads](https://www.python.org/downloads/) (or `brew install python`).
2. Double-click **Job Agent.command** in this folder.
   - The first time, macOS may say it cannot verify the file: right-click
     it, choose **Open**, then **Open** again.
   - The first start prepares itself (about a minute) and asks where to
     keep your job search (press Enter for the `JobAgent` folder in your
     home folder).
3. The app opens in your browser. Keep the Terminal window open while
   you use it; close it, or use **Settings > Quit the app**, to stop.
